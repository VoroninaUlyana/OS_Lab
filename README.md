# Лабораторная работа: Потоки в Windows (C++)

## Описание
Программа создаёт рабочий поток, который обрабатывает массив чисел и подсчитывает количество нечётных элементов.  
Главный поток управляет рабочим: может приостанавливать его (`SuspendThread`), возобновлять (`ResumeThread`) и ожидать завершения (`WaitForSingleObject`).
