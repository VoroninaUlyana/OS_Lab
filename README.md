# Thread Creation in Win32 API (Lab 1)

Данный проект представляет собой консольное приложение на C++, демонстрирующее базовые принципы многопоточного программирования в операционной системе Windows с использованием Win32 API.

## 📝 Описание задачи

Программа создает два потока: **main** (главный) и **worker** (рабочий). Потоки взаимодействуют через передачу структур данных и управляются с помощью системных вызовов для приостановки и возобновления работы.

### Роль потока main:

* Формирование массива (ввод пользователя или случайная генерация).
* Создание потока **worker** двумя способами на выбор: `CreateThread` и `_beginthreadex`.
* Управление состоянием потока: создание в подвешенном состоянии (`CREATE_SUSPENDED`), ожидание и запуск с помощью `ResumeThread`.
* Синхронизация через `WaitForSingleObject` и корректное закрытие дескрипторов.

### Роль потока worker (Индивидуальный вариант):

* Подсчет количества **нечетных элементов** в переданном массиве.
* Имитация длительной работы с помощью `Sleep()` для наглядности управления потоком.

## 🚀 Инструкция по запуску

1. Скомпилируйте проект в среде **Visual Studio** (рекомендуется MSVC).
2. Запустите программу.
3. Введите размер массива.
4. Выберите способ заполнения массива (случайно или вручную).
5. Укажите время (в миллисекундах), на которое главный поток «заснет», прежде чем активировать рабочий поток.
6. Выберите метод создания потока (WinAPI или C Runtime Library).

## 📖 Ответы на вопросы

### 1. Что такое дескриптор (Handle) и идентификатор (ID)?

* **Идентификатор (Thread ID):** Уникальное числовое значение в системе, которое однозначно определяет поток во всей ОС, пока он существует. Используется для системных инструментов (например, Диспетчер задач).
* **Дескриптор (Handle):** Локальный указатель внутри процесса на системный объект. Позволяет процессу управлять потоком (менять приоритет, завершать, приостанавливать). Один поток может иметь несколько дескрипторов, но только один ID.

### 2. Зачем нужен WaitForSingleObject?

Эта функция заставляет вызывающий поток (main) ждать, пока объект (worker) не перейдет в «сигнальное состояние» (завершится). Без этой функции **main** может завершиться раньше, чем **worker** успеет выполнить вычисления, что приведет к уничтожению ресурсов и некорректному результату.

### 3. Разница между CreateThread и _beginthreadex

* `CreateThread` — это "чистая" функция Win32 API.
* `_beginthreadex` — это обертка из библиотеки времени выполнения C (CRT). Она инициализирует специфические для CRT структуры данных (например, для безопасного использования `errno` или функций работы со строками), что предотвращает небольшие утечки памяти при использовании стандартной библиотеки в многопоточной среде.
