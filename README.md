# Process Synchronization: Download Manager Simulation (Lab 4)

Данный проект представляет собой систему из двух независимых приложений, имитирующую работу менеджера загрузок браузера. Проект демонстрирует использование именованных объектов ядра Windows для синхронизации независимых процессов.

## 📝 Описание задачи

Система моделирует поведение браузера при загрузке большого количества файлов с учетом ограничений сетевого канала и необходимости логирования событий.

### Основные компоненты:

1. **Browser.exe (Управляющий процесс):**
* Регулирует количество одновременно работающих загрузчиков.
* Создает общую среду синхронизации для дочерних процессов.
* Обеспечивает корректное завершение всей системы по требованию пользователя.


2. **Downloader.exe (Рабочий процесс):**
* Имитирует одну задачу по скачиванию и обработке файла.
* Выполняет индивидуальное задание: **подсчет открывающих и закрывающих скобок в текстовой строке**.
* Соблюдает дисциплину доступа к ограниченным ресурсам.

## 🏗 Архитектура решения

Программа реализует классические паттерны многозадачности:

* **Ограничение ресурса:** Использование семафора для предотвращения перегрузки системы.
* **Критическая секция (IPC):** Использование мьютекса для доступа к общему устройству вывода (консоли).
* **Broadcast Signal:** Использование события с ручным сбросом для уведомления неограниченного количества процессов о событии.
