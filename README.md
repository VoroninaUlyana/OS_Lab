# Inter-Process Communication via Anonymous Pipes (Lab 2)

Этот проект представляет собой консольное приложение на C++, демонстрирующее взаимодействие между родительским и дочерним процессами в операционной системе Windows с использованием **неименованных каналов (anonymous pipes)**.

## 📝 Описание задачи

Программа реализует механизм, при котором основной процесс запускает собственную копию в качестве дочернего процесса для выполнения вычислений над массивом целых чисел.

### Режимы работы:

1. **Родительский режим (Parent Mode):**
* Создает два неименованных канала: `Pipe1` (для отправки данных) и `Pipe2` (для получения результата).


* Настраивает перенаправление стандартных потоков ввода-вывода (`stdin`/`stdout`) для дочернего процесса.


* Запускает дочерний процесс с аргументом `child`.


* Передает размер и элементы массива через канал.


* Считывает результат вычислений и выводит его на экран.




2. **Дочерний режим (Child Mode):**
* Считывает данные из стандартного потока ввода.


* Выполняет индивидуальное задание (подсчет количества четных элементов).


* Передает результат обратно родителю через стандартный поток вывода.





## 🛠 Технические детали

* 
**Синхронизация:** Используется функция `WaitForSingleObject` для ожидания завершения дочернего процесса.


* 
**Win32 API:** Для работы с процессами и каналами используются функции `CreateProcess`, `CreatePipe`, `WriteFile`, `ReadFile` и `CloseHandle`.


* 
**Безопасность:** Реализована обработка ошибок всех функций API с выводом системных кодов ошибок Windows.


* **Тестирование:** Встроены внутренние Unit-тесты для проверки логики подсчета элементов.
